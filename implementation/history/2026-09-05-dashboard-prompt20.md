# 확정 20문장 모델 테스트 결과

## 결론

K0·R16·KI20에 같은 20문장을 입력해 60요청·54생성·6사전 차단을 완료했다. 실행 계약은 통과했지만, 세 모델 모두 잘못된 갑목 전제에 동의했다. 실제 연결 원국의 일간은 병화였고 해당 질문의 모델 입력까지 재구성해 확인했다. 계산 결과 전달 실패가 아니라, 전달된 사실과 상충하는 사용자 전제를 바로잡지 못한 응답이다.

R16은 기본 일간·일주와 선택 날짜의 간지를 구분하고 생일 정정·시간 미상을 유지했으나, 상충 전제 교정·시간 범위 유지·요청에 맞는 설명에서 문제가 남았다. 자동 경고 통과 수를 정확도나 사용성 점수로 해석하지 않는다. 자연스러움·해석 의미 품질의 자동 계약은 여전히 `not_measured`이며 새 승인 조건을 추가하지 않는다.

검사기의 한계도 분리해야 한다. 개념 설명이 틀려도 맞는 간지가 포함되면 통과한 응답이 있었고, 반대로 원국 사실인 일간을 정확히 제시했는데 원국 기둥이 없다는 누락 경고가 발생했다. 괄호를 포함한 일간 표현도 세부 사실 오류로 충분히 분류하지 못했다. 이번에는 검사기를 바꾸거나 결과를 유리하게 재채점하지 않고 원래 집계와 관찰을 함께 보존했다.
