공개 원천 100만 건을 모두 쓰기보다, 검증을 통과한 7만~10만 건이 더 낫습니다.

정제 흐름

① 원천 다운로드→ ② 라이선스 태깅→ ③ 한국어/용어 정규화→ ④ KASI 기준 재계산→ ⑤ 모순 문장 제거→ ⑥ 근접중복 제거→ ⑦ 말투 rewrite→ ⑧ chart 기준 group split
핵심: 합성 LLM 답변을 그대로 “정답”으로 믿지 않습니다. 계산값은 코드, 이론은 출처/규칙, 자유 해석은 그 둘과 모순 없는 답변을 정답으로 봅니다.

4. 다운로드 방법

Hugging Face는 datasets로 바로 읽는 방식이 가장 편합니다.

Python에서 바로 로드

uv pip install -U datasets huggingface_hub from datasets import load_dataset nemotron = load_dataset( "rayraykim/Nemotron-Personas-Korea-Saju", split="train" ) yeji = load_dataset("tellang/yeji-processed") translated = load_dataset( "tellang/yeji-bazi-translated-ko", split="train" ) bazi_sft = load_dataset("AmareshHebbar/bazi-sft") yeji_v9 = load_dataset( "tellang/yeji-fortune-telling-ko-v9", "alpaca", split="train" ) nolli = load_dataset( "HAERAE-HUB/NOLLI", "saju", split="test" )

파일로 통째로 받기

# Hugging Face CLI uv pip install -U huggingface_hub hf download rayraykim/Nemotron-Personas-Korea-Saju \ --repo-type dataset --local-dir data/nemotron_saju hf download tellang/yeji-bazi-translated-ko \ --repo-type dataset --local-dir data/yeji_translated hf download tellang/yeji-bazi-rules \ --repo-type dataset --local-dir data/yeji_rules # AI Hub: 로그인 후 데이터 페이지에서 신청/다운로드 # KASI: 공공데이터포털 서비스키 발급 → Open API 호출
대용량 팁: Nemotron 1M은 처음부터 전부 메모리에 올리지 말고 streaming 또는 parquet 단위 샘플링으로 품질 검사를 먼저 하세요.

5. 무엇을 “정답”으로 학습할까?

정답의 종류를 분리해야 합성 데이터의 오류를 모델이 그대로 외우지 않습니다.

① 계산 정답연·월·일·시주, 십신, 오행 등 → 고정 정책 runtime 엔진. KASI는 음양력·달력 field만 대조.
② 이론 정답규칙·정의·예외 → 출처가 있는 rule graph.
③ 해석 정답계산 facts + 적용 규칙에 모순되지 않는 자연스러운 답변.
④ 대화 정답사주를 억지로 꺼내지 않고 질문 의도에 맞게 친절하게 응답.
추천 split: 행 랜덤 분할 대신 동일 명식(chart signature)이 train/test에 동시에 들어가지 않도록 group split. NOLLI 300은 모델 split이 아니라 runtime 계산 비교 fixture로 분리.

6. 바로 시작할 때의 최소 순서

1 · runtime 계산 fixture 잠금→ 2 · 공개 원천 4종 다운로드→ 3 · 2~5K 샘플 수동 감사→ 4 · 계산/용어 validator 제작→ 5 · 10K 스모크 SFT→ 6 · 오류 유형 기반 재정제→ 7 · 70~100K 최종 POC

처음부터 100K를 만들지 말고, 10K → 40K → 70~100K로 키우는 편이 데이터 오류와 모델 성향을 빠르게 잡기 좋습니다.
