주의R-KI10-QUALITY-TARGET

Gate v2 지식·정책 목표 미달

원국 글자 12/12는 통과했지만 지장간 7/12·천간 십신 0/12·지지 십신 1/12·handoff 행동 7/50 등 8개 목표가 미달했습니다.

기술 실험 지속과 배포 품질 승격을 분리합니다. KI20 실험 결과는 품질 인증이 아니며 sealed blind와 배포는 계속 금지합니다.
주의R-TOKENIZER-REGEX

Mistral regex 호환 경고

base snapshot과 KI10 final tokenizer 파일 SHA-256은 동일하지만 현재 Transformers가 Mistral regex 호환 경고를 냅니다.

이번 비교에서는 토큰 fingerprint를 보존하고 fix_mistral_regex를 적용하지 않습니다. 변경은 별도 tokenizer·data·run version에서 검증합니다.
주의R-LOSS-AGGREGATION

loss 집계 단위 차이

과거 Trainer eval loss와 이번 전체 supervised-token micro NLL은 집계 단위가 달라 절대값을 직접 비교할 수 없습니다.

표준 assistant-only chunked NLL을 유지하고 macro·micro loss는 진단값으로만 사용하며 자동 품질 Gate에는 넣지 않습니다.
